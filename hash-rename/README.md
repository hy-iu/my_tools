# hash-rename

按文件内容哈希分组，并让你逐组选择“保留哪个文件名”。它适合处理两组目录中内容相同、路径或名称不同的图片/视频。

第一版是 Python 标准库本地 WebUI：不用安装 Flask、Node 或数据库。它只做重命名，不复制、不删除文件。

## 运行

在 Windows PowerShell 中：

```powershell
cd C:\Users\hy-wu.DESKTOP-G355NC5\Projects\my_tools\hash-rename
py -3.12 hash_rename.py
```

然后打开 <http://127.0.0.1:8765/>。

也可以指定端口：

```powershell
py -3.12 hash_rename.py --port 8766
```

## 使用流程

1. 每行输入一个要扫描的文件夹，例如 `I:\Pictures` 和 `F:\Favorites\m`。
2. 选择 SHA-256（默认），点击“开始扫描”。扫描先按文件大小筛选，再对候选文件流式计算哈希。
3. 默认隐藏“内容相同且文件名也完全相同”的哈希组；需要时可勾选“显示完全同名组”。
4. 每个哈希组中，单选一个文件作为“名称来源”，或填写自定义名称；再勾选要改名的其他文件。可在扫描前填写“默认名称来源文件夹”，工具会优先选其中的文件名。
5. 步骤 2 会实时标出阻断冲突：目标名已存在，或同目录多个目标会改成同一个名字。通过换名称来源、填写自定义名称或取消对应目标处理；步骤 3 只做最终汇总确认。
6. 点击“生成重命名计划”，检查每一条旧路径和新路径。
7. 处理所有冲突后，点击“执行计划”。执行前会再次验证源文件哈希，防止扫描后文件被替换。
8. 执行记录写入 `history.jsonl`，可以在页面底部逐笔撤销。

## 安全规则

- 默认扫描和预览，不会改变文件系统。
- 只执行同目录文件重命名；不会复制、删除或移动文件。
- 目标文件名已存在、多个目标会得到同一名称、源文件内容发生变化时，整批计划拒绝执行。
- 文件名用方括号显示并保留空白；例如 `[ _1.jpg]` 与 `[_1.jpg]` 可直接区分。
- 执行采用临时名称分两阶段处理，支持大小写改名和名称交换，避免中途覆盖。
- 服务只绑定 `127.0.0.1`，不向局域网开放。
- 目前历史记录保存在项目目录的 `history.jsonl`；不要把它提交到仓库。
