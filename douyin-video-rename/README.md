# douyin-video-rename

抖音下载文件整理工具：把无意义标题（`神待福瑞的抖音 - 抖音 (N).mp4`）的动图/视频
重命名为有意义标题，或与 `~/Pictures` 下新下载的帖子图片建立对应关系。

## 背景

抖音下载器会把同一个帖子存成多种文件：

- 图片帖 → `~/Pictures/<作者_标题>/01.jpg, 02.jpg, ...`
- 视频/动图 → 下载目录下 `神待福瑞的抖音 - 抖音 (N).mp4`（无意义标题）

部分视频有对应的低分辨率版本（有意义标题），部分动图对应新下载的帖子图片。

## 脚本

| 脚本 | 用途 |
|---|---|
| `common.py` | 共享工具：感知哈希、ffmpeg/ffprobe 封装、宽高比 |
| `match_videos.py` | 视频↔视频匹配（无意义标题 ↔ 低分辨率有意义标题） |
| `rename_videos.py` | 按匹配结果重命名并生成完整记录文件 |
| `match_images.py` | 动图视频 ↔ 帖子图片匹配，四级分类报告 |
| `抖音视频重命名记录.txt` | 首次重命名的完整记录（18 个文件） |
| `动图图片匹配报告_2026-08-02.txt` | 动图↔图片匹配报告（74 个视频） |

## 匹配原理

1. **内容哈希**：ffmpeg 抽取关键帧（视频首帧/25%/50%/75%）缩放为
   32x32 灰度图，计算 64 位 difference hash（dhash），逐对比较汉明距离。
2. **宽高比校验**：候选对宽高比相对差需 < 25%。
3. **下载时间交叉验证**：视频下载时间与图片文件夹修改时间差 < 3 分钟
   （同一个帖子在同一个下载会话中处理），作为帖子级对应关系的独立证据。
4. **分级**：
   - `STRONG`：哈希距离 ≤ 8 且宽高比一致（确定对应）
   - `GOOD`：哈希距离 ≤ 14 且时间差 < 3 分钟（很可能对应）
   - `POST`：仅时间差 < 3 分钟（帖子级对应，具体哪张图不确定）
   - `NONE`：无对应

## 用法（以后每次下载后运行）

```bash
cd ~/Documents/GitHub/my_tools/douyin-video-rename

# 第一步：匹配（找出仍为"神待福瑞*"且内容与有意义标题视频相同的文件）
python3 match_videos.py /Users/bjergsen/Downloads

# 第二步：预览重命名（dry-run，不实际改名）
python3 rename_videos.py matches.json

# 确认无误后执行，并自动追加记录到 抖音视频重命名记录.txt
python3 rename_videos.py matches.json --go
```

匹配原理：每段视频单次 ffmpeg 均匀提取 8 帧 32x32 灰度图，计算 64 位
感知哈希；要求时长差 ≤2s 且 8 帧中至少 6 帧哈希距离 ≤8。
脚本只处理当前仍以「神待福瑞」开头的文件，已重命名的不会重复处理。

## 已知发现（2026-08-02 会话）

- 92 个无意义标题视频中 18 个有低分辨率版本，已重命名为
  `有意义标题_宽x高.mp4`（记录见 `抖音视频重命名记录.txt`）。
- 剩余 74 个动图视频中：8 个 STRONG、34 个 GOOD、22 个 POST、
  10 个 NONE。其中 43 个视频（编号 20–62）与「饭不着憋着饿…」帖子的
  43 张图片构成一个簇，序号线性对应（下载顺序 = 图片顺序）。
